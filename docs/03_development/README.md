# 03 Development

실제 구현 코드를 보관한다.

## 폴더

- `01_backend`: Spring Boot, MyBatis, API, 인증, 비즈니스 로직
- `02_frontend`: React 화면 구현
- `03_ai`: Python AI Worker, STT, 요약, 추출, 리뷰 처리
- `04_database`: PostgreSQL DDL, migration, seed data

## 개발 원칙

- 요구사항 ID와 테스트 케이스 ID를 코드 작업 단위에 연결한다.
- 기능 구현 전 API/DB/화면 설계를 먼저 확인한다.
- 핵심 도메인은 DDD 문서와 함께 모델링한다.
- 가능한 범위에서 TDD 흐름을 따른다.
