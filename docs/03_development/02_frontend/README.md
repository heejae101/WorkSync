# Frontend

React 기반 프론트엔드 코드를 보관한다.

## 책임

- 사이드바 폴더/파일 트리
- 폴더 비밀번호 확인 화면
- 파일 목록 기반 md/html/json/회의록/주간보고/마감일 생성, 조회, 수정, 삭제 화면
- 메인 대시보드
- 개인/공유 세션 입장 및 열람권 관리
- 공유 세션 채팅 화면
- 공통 컴포넌트

## 추천 구조

```text
frontend/
├── src/pages
├── src/components
├── src/features
├── src/api
└── src/styles
```

## 실행 방법

```bash
cd frontend
npm install
npm run dev
```

## 검토 필요

- API 연동 전 단계이므로 업무 데이터는 브라우저 메모리 상태로만 유지된다. 단, 개인/공유 열람권은 30분 만료 쿠키로 보관한다.
- 파일 저장 방식, 업로드 제한, AI 처리 실패 상태는 백엔드/API 계약 확정 후 연결해야 한다.
