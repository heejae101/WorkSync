# TDD 계획

## 목적
핵심 기능을 테스트 가능한 단위로 쪼개고 실패 테스트부터 작성한다.

## TDD 대상 후보

| 기능 | 테스트 대상 | 우선순위 |
|---|---|---|
| 로그인 | 인증 성공/실패, 접근 제한 | MVP |
| 개인 세션 | 생성/조회/수정 | MVP |
| 공유 세션 | 초대/참여자 조회 | MVP |
| 데드라인 추출 | AI 결과 파싱/상태 저장 | MVP |
| 주간 보고 | 데이터 수집/초안 생성 | MVP |
