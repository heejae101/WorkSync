# 엔터티 정의서

| 엔터티 | 물리명 후보 | 설명 | 주요 속성 | 비고 |
|---|---|---|---|---|
| 사용자 | users | 서비스 사용자 | id, email, password_hash, name | 로그인 필수 |
| 세션 | sessions | 개인/공유 업무 공간 | id, owner_id, title, type, status | type: PERSONAL/SHARED |
| 세션 참여자 | session_members | 공유 세션 참여자 | id, session_id, user_id, role | 권한 모델 확장 가능 |
| 세션 콘텐츠 | session_contents | 세션 내 기록/파일/AI 결과 | id, session_id, content_type, body | 텍스트/이미지/파일 |
| 회의록 요약 | meeting_summaries | 전사/요약 결과 | id, session_id, transcript, summary | 파일 출력 연동 |
| 데드라인 | deadlines | 추출 또는 직접 등록한 마감 | id, user_id, title, due_at, status | 캘린더 표시 |
| 주간 보고 | weekly_reports | 주간 보고 초안/최종본 | id, user_id, period_start, period_end, content | |
| 시간 기록 | time_logs | 하루 업무 기록 | id, user_id, logged_at, content, category | 대시보드 |
| 리서치 노트 | research_notes | 기술/논문 리서치 결과 | id, user_id, topic, summary, sources | 출처 필요 |
| 코드 리뷰 요청 | code_review_requests | GitHub 리뷰 요청 | id, user_id, repository, ref, result | 후순위 |
