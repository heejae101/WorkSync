# 엔터티 정의서

| 엔터티 | 물리명 후보 | 설명 | 주요 속성 | 비고 |
|---|---|---|---|---|
| 폴더 | folders | 개인/공유 세션을 구분하는 사이드바 단위 | id, parent_id, name, type, password_hash, status | type: PERSONAL/SHARED |
| 세션 파일 | session_files | 폴더 안에 생성되는 md/html/json 파일 | id, folder_id, name, extension, content_markdown, content_html, content_json | 저장 방식 검토 필요 |
| 파일 버전 | file_versions | 파일 수정 이력 | id, file_id, version_no, content_snapshot, created_alias | TDD 대상 |
| 세션 참여자 | session_members | 공유 세션 참여자 | id, folder_id, alias, role | 계정 없이 별칭 기록 |
| 폴더 접근 이력 | folder_access_logs | 잠긴 폴더 접근 시도 기록 | id, folder_id, alias, result, accessed_at | 감사/트러블슈팅 |
| AI 작업 | ai_jobs | STT, 회의록, 시간 기록, 데드라인 추출 같은 비동기 AI 작업 | id, file_id, job_type, provider, status | 재시도/실패 기록 필요 |
| AI 결과 | ai_results | AI 작업 결과 원문과 구조화 결과 | id, job_id, result_type, content_text, content_json | 검토 후 확정 |
| 회의록 요약 | meeting_summaries | 전사/요약 결과 | id, file_id, transcript, summary | 파일 출력 연동 |
| 데드라인 | deadlines | 추출 또는 직접 등록한 마감 | id, file_id, title, due_at, status | 캘린더 표시 |
| 주간 보고 | weekly_reports | 주간 보고 초안/최종본 | id, file_id, period_start, period_end, content | |
| 시간 기록 | time_logs | 하루 업무 기록 | id, file_id, logged_at, content, category | 대시보드 |
| 리서치 노트 | research_notes | 기술/논문 리서치 결과 | id, file_id, topic, summary, sources | 출처 필요 |
| 코드 리뷰 요청 | code_review_requests | GitHub 리뷰 요청 | id, file_id, repository, ref, result | 후순위 |
