# 컬럼 정의서

## 작성 규칙

- 컬럼명은 snake_case를 기본으로 한다.
- 기본키는 `id`를 사용한다.
- 생성/수정 일시는 `created_at`, `updated_at`을 사용한다.
- 삭제 정책은 물리 삭제/논리 삭제 중 테이블별로 결정한다.

## users

| 컬럼명 | 타입 | Nullable | Key | 설명 |
|---|---|---|---|---|
| id | BIGSERIAL | N | PK | 사용자 ID |
| email | VARCHAR(255) | N | UK | 로그인 이메일 |
| password_hash | VARCHAR(255) | N | | 비밀번호 해시 |
| name | VARCHAR(100) | N | | 사용자 이름 |
| created_at | TIMESTAMP | N | | 생성 일시 |
| updated_at | TIMESTAMP | N | | 수정 일시 |

## sessions

| 컬럼명 | 타입 | Nullable | Key | 설명 |
|---|---|---|---|---|
| id | BIGSERIAL | N | PK | 세션 ID |
| owner_id | BIGINT | N | FK | 생성자 ID |
| title | VARCHAR(255) | N | | 세션 제목 |
| type | VARCHAR(20) | N | | PERSONAL, SHARED |
| status | VARCHAR(20) | N | | ACTIVE, ARCHIVED |
| created_at | TIMESTAMP | N | | 생성 일시 |
| updated_at | TIMESTAMP | N | | 수정 일시 |
