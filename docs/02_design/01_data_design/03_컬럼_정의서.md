# 컬럼 정의서

## 작성 규칙

- 컬럼명은 snake_case를 기본으로 한다.
- 기본키는 `id`를 사용한다.
- 생성/수정 일시는 `created_at`, `updated_at`을 사용한다.
- 삭제 정책은 물리 삭제/논리 삭제 중 테이블별로 결정한다.

## sessions

| 컬럼명              | 타입           | Nullable | Key | 설명                                           |
| ---------------- | ------------ | -------- | --- | -------------------------------------------- |
| id               | BIGSERIAL    | N        | PK  | 세션(문서) ID                                    |
| user_id          | VARCHAR(50)  | Y        |     | 임시 사용자 구분 코드 ('USER_1', 'USER_2', 'ADMIN')   |
| title            | VARCHAR(255) | N        |     | 세션(회의) 제목                                    |
| session_type     | VARCHAR(50)  | N        |     | 문서/세션 종류 (PERSONAL, SHARED, WEEKLY_REPORT 등) |
| content_markdown | TEXT         | Y        |     | 에디터 문서 원본 데이터 (Markdown 등)                   |
| content_result   | TBD          | Y        |     | 렌더링 결과 및 메타데이터 (라이브러리 확정 후 타입 결정)            |
| status           | VARCHAR(20)  | N        |     | ACTIVE, ARCHIVED                             |
| created_at       | TIMESTAMP    | N        |     | 생성 일시                                        |
| updated_at       | TIMESTAMP    | N        |     | 수정 일시                                        |

## session_members

| 컬럼명        | 타입           | Nullable | Key | 설명            |
| ---------- | ------------ | -------- | --- | ------------- |
| id         | BIGSERIAL    | N        | PK  | 참여자 매핑 ID     |
| session_id | BIGINT       | N        | FK  | 공유 세션 ID      |
| user_id    | VARCHAR(50)  | N        |     | 참여 중인 임시 사용자 코드 ('USER_1' 등) |
| role       | VARCHAR(20)  | N        |     | OWNER, MEMBER |
| created_at | TIMESTAMP    | N        |     | 생성 일시         |

## ai_tasks

| 컬럼명         | 타입          | Nullable | Key | 설명                                  |
| ----------- | ----------- | -------- | --- | ----------------------------------- |
| id          | BIGSERIAL   | N        | PK  | AI 작업 ID                            |
| session_id  | BIGINT      | N        | FK  | 대상 세션 ID                            |
| job_type    | VARCHAR(30) | N        |     | STT, MEETING_MINUTES, REPORT 등      |
| status      | VARCHAR(20) | N        |     | PENDING, RUNNING, SUCCEEDED, FAILED |
| error_log   | TEXT        | Y        |     | 실패 시 오류 로그                          |
| result_text | TEXT        | Y        |     | STT 전사 텍스트 등 자연어 결과 원본              |
| result_json | JSONB       | Y        |     | 요약 구조화 데이터(안건, 결정사항, 마감일 등) 파싱 저장   |
| created_at  | TIMESTAMP   | N        |     | 생성 일시                               |
| updated_at  | TIMESTAMP   | N        |     | 수정 일시                               |

## status_codes

| 컬럼명         | 타입           | Nullable | Key | 설명                                         |
| ----------- | ------------ | -------- | --- | ------------------------------------------ |
| id          | BIGSERIAL    | N        | PK  | 상태 코드 ID                                   |
| group_code  | VARCHAR(50)  | N        |     | 상태 그룹명 (예: SESSION_STATUS, AI_TASK_STATUS) |
| code_value  | VARCHAR(50)  | N        |     | 실제 데이터베이스 저장 값 (예: ACTIVE, PENDING)        |
| code_name   | VARCHAR(100) | N        |     | 화면 표시용 상태 이름 (예: 활성, 대기중)                  |
| description | TEXT         | Y        |     | 상태에 대한 상세 설명                               |
| created_at  | TIMESTAMP    | N        |     | 생성 일시                                      |

## 제외/후순위 대상 (MVP 제외 또는 타 테이블에 통합)

- weekly_reports (`sessions` 테이블에 session_type='WEEKLY_REPORT'로 통합)
- deadlines (`sessions`의 content_json 또는 `ai_tasks`의 result_json 내에 통합)
- time_logs (`sessions`의 content_json 내 메타데이터로 통합)
- file_versions (Phase 4 연기)
- folder_access_logs (비밀번호 기능 배제로 제외)
- research_notes (후순위 연기)
- code_review_requests (후순위 연기)
