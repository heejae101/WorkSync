# 컬럼 정의서

## 작성 규칙

- 컬럼명은 snake_case를 기본으로 한다.
- 기본키는 `id`를 사용한다.
- 생성/수정 일시는 `created_at`, `updated_at`을 사용한다.
- 삭제 정책은 물리 삭제/논리 삭제 중 테이블별로 결정한다.

## folders

| 컬럼명 | 타입 | Nullable | Key | 설명 |
|---|---|---|---|---|
| id | BIGSERIAL | N | PK | 폴더 ID |
| parent_id | BIGINT | Y | FK | 상위 폴더 ID |
| name | VARCHAR(255) | N | | 폴더명 또는 공유 세션명 |
| type | VARCHAR(20) | N | | PERSONAL, SHARED |
| password_hash | VARCHAR(255) | Y | | 폴더 비밀번호 해시, 비밀번호 없으면 NULL |
| status | VARCHAR(20) | N | | ACTIVE, ARCHIVED |
| created_at | TIMESTAMP | N | | 생성 일시 |
| updated_at | TIMESTAMP | N | | 수정 일시 |

## session_files

| 컬럼명 | 타입 | Nullable | Key | 설명 |
|---|---|---|---|---|
| id | BIGSERIAL | N | PK | 파일 ID |
| folder_id | BIGINT | N | FK | 소속 폴더 ID |
| name | VARCHAR(255) | N | | 파일명 |
| extension | VARCHAR(20) | N | | md, html, json |
| content_markdown | TEXT | Y | | Markdown 원본 |
| content_html | TEXT | Y | | HTML 렌더링 결과 또는 HTML 원본 |
| content_json | JSONB | Y | | AI 결과, 메타데이터, 구조화 문서 데이터 |
| status | VARCHAR(20) | N | | ACTIVE, ARCHIVED |
| created_at | TIMESTAMP | N | | 생성 일시 |
| updated_at | TIMESTAMP | N | | 수정 일시 |

## session_members

| 컬럼명 | 타입 | Nullable | Key | 설명 |
|---|---|---|---|---|
| id | BIGSERIAL | N | PK | 참여자 ID |
| folder_id | BIGINT | N | FK | 공유 세션 폴더 ID |
| alias | VARCHAR(100) | N | | 참여자 별칭 |
| role | VARCHAR(20) | N | | OWNER, MEMBER |

## ai_jobs

| 컬럼명 | 타입 | Nullable | Key | 설명 |
|---|---|---|---|---|
| id | BIGSERIAL | N | PK | AI 작업 ID |
| file_id | BIGINT | N | FK | 대상 파일 ID |
| job_type | VARCHAR(30) | N | | STT, MEETING_MINUTES, TIME_LOG, DEADLINE, REPORT |
| provider | VARCHAR(30) | N | | external_api, local_model, terminal_bridge |
| status | VARCHAR(20) | N | | PENDING, RUNNING, SUCCEEDED, FAILED, RETRYING |
| request_json | JSONB | Y | | AI 요청 파라미터 |
| error_message | TEXT | Y | | 실패 원인 |
| created_at | TIMESTAMP | N | | 생성 일시 |
| updated_at | TIMESTAMP | N | | 수정 일시 |

## ai_results

| 컬럼명 | 타입 | Nullable | Key | 설명 |
|---|---|---|---|---|

| job_id | BIGINT | N | FK | AI 작업 ID |
| result_type | VARCHAR(30) | N | | TRANSCRIPT, SUMMARY, TIME_LOG, DEADLINE |

| content_json | JSONB | Y | | 구조화 결과 |
