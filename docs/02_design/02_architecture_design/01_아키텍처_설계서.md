# 아키텍처 설계서

## 문서 목적
회사도우미의 시스템 구성, 인프라, 주요 흐름을 정의한다.

## 기술 스택 초안

| 영역 | 기술 | 비고 |
|---|---|---|
| Frontend | React | 화면 구현 |
| Backend | Spring Boot | 인증, API, 비즈니스 로직 |
| Persistence | MyBatis | SQL 중심 데이터 접근 |
| Database | PostgreSQL | 주요 업무 데이터 저장 |
| AI 처리 | Python 또는 외부 AI API | STT, 요약, 추출, 리뷰 |
| SCM | GitHub | 코드 관리 |
| 협업 | Notion | 기획/문서 협업 |

## 시스템 구성도

```text
[Browser]
   |
   v
[React Frontend]
   |
   v
[Spring Boot API]
   |         \
   v          v
[PostgreSQL] [AI Worker/API]
              |
              v
        [LLM/STT/Research Tools]
```

## 주요 흐름

### 회의록 요약

```text
사용자 파일 업로드
-> Spring API 파일 접수
-> AI 처리 요청
-> STT 결과 생성
-> 요약 결과 생성
-> DB 저장
-> 화면 표시/다운로드
```

### 데드라인 추출

```text
회의록/세션 기록 저장
-> AI 마감일 추출
-> 후보 마감일 생성
-> 사용자 확인
-> 캘린더 등록
-> 메인 페이지 임박 항목 표시
```

## 설계 결정 필요 사항

- AI Worker를 별도 Python 서버로 둘지 여부
- 파일 저장소 위치
- 인증 방식: 세션, JWT, Spring Security 세부 구성
- 실시간 공유: WebSocket, SSE, polling 중 선택
- 배포 환경: 로컬, 사내 서버, 클라우드 중 선택
