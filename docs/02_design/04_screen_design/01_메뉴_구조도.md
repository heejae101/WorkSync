# 메뉴 구조도

## 메뉴 트리

```text
회사도우미
├── 로그인
└── 메인
    ├── 대시보드
    ├── 개인 세션
    │   ├── 세션 목록
    │   └── 세션 상세
    ├── 공유 세션
    │   ├── 공유 방 목록
    │   ├── 공유 방 상세
    │   └── 초대 관리
    ├── 회의록 요약
    ├── 주간 보고
    ├── 캘린더/데드라인
    ├── 시간 기록 대시보드
    ├── 코드 리뷰
    ├── 리서치
    └── 설정
```

## 메뉴별 설명

| 메뉴 | 설명 | MVP 여부 |
|---|---|---|
| 로그인 | 서비스 접근 인증 | Y |
| 대시보드 | 임박 데드라인, 최근 세션, 최근 산출물 | Y |
| 개인 세션 | 개인 업무 기록 및 AI 요약 | Y |
| 공유 세션 | 협업 세션과 초대 | Y |
| 회의록 요약 | 녹음 업로드, 전사, 요약, 출력 | Y |
| 주간 보고 | 주간 보고 초안 생성 | Y |
| 캘린더/데드라인 | 마감일 관리 | Y |
| 시간 기록 대시보드 | 하루/주간 업무 기록 | 후보 |
| 코드 리뷰 | GitHub 기반 AI 리뷰 | 후순위 |
| 리서치 | 기술/논문 리서치 | 후순위 |
