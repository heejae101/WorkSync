# 06 Study

팀원들과 공유할 학습 자료, 실습 기록, 기술 선택 이유를 관리한다.

## 목적

- 프로젝트에 필요한 기술을 팀이 같은 기준으로 학습한다.
- 학습 내용이 실제 설계/개발 결정으로 이어지도록 기록한다.
- 기술 선택 이유와 트러블슈팅을 남겨 나중에 다시 설명할 수 있게 한다.

## 학습 주제

| 분류 | 주제 | 목적 | 상태 |
|---|---|---|---|
| Backend | Spring Boot | API, 인증, 비즈니스 로직 구현 | 예정 |
| Backend | MyBatis | SQL 기반 DB 연동 | 예정 |

| AI | Python AI Worker | STT, 요약, 추출 처리 | 예정 |
| AI | LangGraph | AI 워크플로우 구성 | 예정 |

| Engineering | TDD | 테스트 우선 개발 | 예정 |
| Engineering | DDD | 도메인 중심 설계 | 예정 |
| Collaboration | GitHub | 브랜치 전략, PR, 리뷰 | 예정 |
