# 화면 표준 정의서

## 문서 목적
회사도우미 화면의 공통 UI, 레이아웃, 컴포넌트, 스타일 규칙을 정의한다.

## 디자인 원칙

- 업무 도구답게 조용하고 명확한 화면을 우선한다.
- 메인 화면에서는 임박 데드라인, 최근 세션, 최근 산출물을 빠르게 확인할 수 있어야 한다.
- AI 결과물은 항상 사용자가 검토하고 수정할 수 있어야 한다.
- 개인 세션과 공유 세션의 상태를 명확히 구분한다.
- 화면 구성은 반복 업무에 적합하게 과한 장식을 피한다.

## 공통 레이아웃

| 영역 | 설명 |
|---|---|
| Header | 서비스명, 사용자 메뉴, 알림 진입 |
| Sidebar | 메뉴 구조, 세션 목록, 주요 기능 진입 |
| Main Content | 선택된 업무 화면 |
| Right Panel | 상세 정보, AI 결과, 활동 로그 |
| Modal/Drawer | 초대, 파일 업로드, 상세 설정 |

## 공통 컴포넌트

| 컴포넌트 | 사용 위치 | 상태 |
|---|---|---|
| Button | 주요/보조 액션 | default, hover, disabled, loading |

## 화면 상태

| 상태 | 정의 | 표시 방식 |
|---|---|---|
| Loading | 데이터 조회 중 | 스켈레톤 또는 로딩 표시 |
| Empty | 데이터 없음 | 다음 행동 버튼 제공 |
| Error | 처리 실패 | 오류 메시지와 재시도 |
| Permission | 권한 없음 | 접근 불가 안내 |
| Dirty | 저장되지 않은 변경 | 이탈 전 확인 |

## 접근성/사용성 기준

- 버튼과 링크는 키보드로 접근 가능해야 한다.
- 입력 오류는 필드 가까이에 표시한다.
- 삭제/초대/공유 같은 영향이 큰 액션은 확인 절차를 둔다.
- AI 생성 결과는 원본 데이터와 생성 결과를 함께 확인할 수 있어야 한다.
