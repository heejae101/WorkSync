# 프로세스 계층도

## 문서 목적
회사도우미의 주요 업무 프로세스를 상위 업무, 하위 업무, 세부 기능 단위로 구조화한다.

## Level 1 업무 영역

```text
회사도우미
├── 1. 인증/사용자
├── 2. 개인 세션
├── 3. 공유 세션
├── 4. 회의록 요약
├── 5. 주간 보고
├── 6. 데드라인 관리
├── 7. AI 코드 리뷰
├── 8. 시간 기록 대시보드
└── 9. 기술 리서치
```

## Level 2 프로세스

| Level 1 | Level 2 | 설명 | 우선순위 |
|---|---|---|---|
| 인증/사용자 | 로그인 | 회원만 서비스 접근 | MVP |
| 개인 세션 | 세션 생성 | 개인 업무 기록 공간 생성 | MVP |
| 개인 세션 | 기록 작성 | 텍스트/파일/음성 기록 | MVP |
| 공유 세션 | 공유 방 생성 | 참여자와 함께 쓰는 공간 생성 | MVP |
| 공유 세션 | 초대 | 사용자 초대 | MVP |
| 회의록 요약 | 파일 업로드 | 녹음 파일 등록 | MVP |
| 회의록 요약 | STT | 음성을 텍스트로 변환 | MVP |
| 회의록 요약 | AI 요약 | 회의 내용을 요약 | MVP |
| 주간 보고 | 소스 수집 | 세션/회의록/시간 기록 수집 | MVP |
| 주간 보고 | AI 초안 | 보고서 초안 생성 | MVP |
| 데드라인 관리 | 마감 추출 | 요약에서 일정 추출 | MVP |
| 데드라인 관리 | 캘린더 표시 | 메인/캘린더 노출 | MVP |
| AI 코드 리뷰 | GitHub 연결 | 저장소/PR 연동 | 후순위 |
| 시간 기록 대시보드 | 하루 기록 | 음성/텍스트 기록 저장 | MVP 후보 |
| 기술 리서치 | 자료 수집 | 검색/논문/문서 수집 | 후순위 |
