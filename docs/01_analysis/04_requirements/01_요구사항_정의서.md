# 요구사항 정의서

## 문서 목적
회사도우미의 기능 요구사항, 비기능 요구사항, 우선순위, 검증 기준을 정의한다.

## 요구사항 목록

| ID | 구분 | 요구사항 | 우선순위 | 수용 기준 | 관련 화면 | 관련 API | 상태 |
|---|---|---|---|---|---|---|---|
| REQ-FOLDER-001 | 기능 | 사용자는 사이드바에서 폴더를 생성하고 폴더별 세션을 구분할 수 있다. | MVP | 개인/공유 폴더가 생성되고 사이드바 트리에 표시된다. | 사이드바 | Folder API | 결정 |
| REQ-FOLDER-002 | 기능 | 사용자는 폴더 안에 파일을 생성할 수 있다. | MVP | 폴더에 md/html/json 파일이 생성되고 저장된다. | 파일 편집 | File API | 결정 |
| REQ-FOLDER-SEC-001 | 보안 | 개인 폴더는 비밀번호를 설정해 접근을 제한할 수 있다. | MVP | 비밀번호가 설정된 폴더는 검증 후에만 열린다. | 폴더 잠금 | Folder API | 결정 |
| REQ-SHARE-001 | 기능 | 사용자는 공유 세션 폴더를 이름, 선택 비밀번호, 별칭 기준으로 사용할 수 있다. | MVP | 참여자가 별칭으로 입장하고 작성 이력이 별칭 기준으로 기록된다. | 공유 세션 | Share API | 결정 |
| REQ-AUDIO-001 | 기능 | 회의록과 시간 기록은 공통 음성 입력/STT 파이프라인을 사용한다. | MVP | 한 번 업로드한 음성 원문을 회의록 또는 시간 기록으로 분기 처리할 수 있다. | 회의록 요약, 시간 대시보드 | Audio API | 결정 |
| REQ-MEETING-001 | 기능 | 사용자는 녹음 파일을 업로드해 회의록 요약을 생성할 수 있다. | MVP | 전사 결과와 요약 결과가 생성된다. | 회의록 요약 | Meeting API | 초안 |
| REQ-WEEKLY-001 | 기능 | 사용자는 기록 데이터를 기반으로 주간 보고 초안을 생성할 수 있다. | MVP | 선택 기간의 보고서 초안이 생성된다. | 주간 보고 | Report API | 초안 |
| REQ-DEADLINE-001 | 기능 | 시스템은 AI 요약 결과에서 마감일을 추출할 수 있다. | MVP | 추출된 마감일이 캘린더에 표시된다. | 캘린더 | Deadline API | 초안 |
| REQ-REVIEW-001 | 기능 | 시스템은 GitHub 변경사항을 기반으로 AI 코드 리뷰를 제공할 수 있다. | 후순위 | PR diff에 대한 리뷰 결과가 생성된다. | 코드 리뷰 | Review API | 초안 |
| REQ-TIME-001 | 기능 | 사용자는 하루 업무 기록을 저장하고 대시보드에서 확인할 수 있다. | MVP 후보 | 일간/주간 기록이 조회된다. | 시간 대시보드 | TimeLog API | 초안 |
| REQ-TIME-002 | 기능 | 시스템은 음성 원문을 시간 기록으로 변환할 때 활동별 가중치를 제안할 수 있다. | MVP 후보 | 시간대, 활동 유형, 중요도/집중도 후보가 생성되고 사용자가 수정할 수 있다. | 시간 대시보드 | TimeLog API | 초안 |
| REQ-RESEARCH-001 | 기능 | 사용자는 기술 주제를 입력해 자료 요약과 비교표를 생성할 수 있다. | 후순위 | 출처가 포함된 요약이 생성된다. | 리서치 | Research API | 초안 |
